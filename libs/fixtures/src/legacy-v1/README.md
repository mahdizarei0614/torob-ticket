# Frozen showcase-v1 / catalog-v1

These modules preserve the complete original generator, schedule, catalog and hotel graph before task0049. Existing session catalogs, provider rechecks and insert-only seed rows retain their original data. Changes belong to a new version, never these files.

`replay-snapshots.json` records pre-expansion SHA-256 fingerprints for all six hero routes, one-way and round-trip, including mixed traveler categories and every provider dialect. Current-version dispatch is regression-tested against these fixed fingerprints.

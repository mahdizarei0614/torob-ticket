# 0059 — Selective word scramble

Date:2026-10-30. Owner follow-up: scramble words can also be used in suitable
places. This extends decision0058 with an explicit opt-in text effect.

Use a short decorative glyph-resolving effect on newly arriving class options
and the comparison-mode heading. Keep whole Persian strings in their text node,
preserving script shaping, spaces and ZWNJ; never split joined letters into
individually transformed spans. Preserve numbers and punctuation. The real
current phrase remains immediately available to assistive technology; intermediate
glyphs and old visuals are hidden from it.

Reserve the final shaped phrase's dimensions so glyph changes do not move the
control, selected indicator or surrounding layout. Use the existing finite
Motion progress and shared reduced/covered/hidden/disabled policy. Cancel or
settle old progress on replacement/unmount; rapid changes resolve to the latest
phrase. Settled unchanged values never replay when the page resumes. No separate
perpetual loop, dependency or GSAP installation is needed.

Default MotionText remains fade/lift. Do not apply scramble to typed values,
prices, dates, route facts, transport codes or ticket rows. Existing semantic
names, input/caret state, current choice authority and48-card rendering remain
unchanged. This is selective decoration, not a new loading or data state.

## OpenStreetMap vector adapter lifecycle and controls

The optional picker lazily imports MapLibre SDK, CSS and the official Vite local worker URL only on open. An adapter owns one active map at a time, defers construction until the SDK resolves, tombstones disposed loaders, tracks exact listeners/markers/ResizeObserver and removes the provider map/DOM on Close/Cancel/reset/unmount. StrictMode cleanup cannot allow a former import or event to mount/mutate a replacement. Load/error timeout is bounded15seconds, and failed style/tile/WebGL/module load removes the map and leaves a truthful unavailable message with retry, local landmark/hotel list and coordinates. There is no dotted or fabricated substitute.

Official light/dark styles are https://vector.openstreetmap.org/styles/shortbread/colorful.json and https://vector.openstreetmap.org/styles/shortbread/shadow.json. setStyle retains camera and provisional point; provider events never submit a hotel query. Map stays 2D with pitch/bearing0, rotation/pitch gestures disabled and accessible zoom controls. Native click.lngLat maps to validated GeoPoint with wrapped longitudes; any valid manual point remains usable internationally. Custom pin dragging is provisional, with exact owned cleanup. Numbered hotel markers have full accessible titles and matching list numbers; names already containing fictional suffixes are not duplicated. Landmarks are bundled local records; accommodation coordinates come from returned Hotel DTOs. No geocoder, Places, GPS, routing, traffic or bulk tile download is used.

OpenStreetMap contributor attribution stays visible; the public CC0 VersaTiles styles are identified separately. Vendor styles and SDK UI are third-party assets; every authored marker/control/surface uses semantic theme tokens. MapLibre6.16 declarations and official docs confirm native Arabic shaping/bidi, so no remote RTL plugin is added. Persian labels still need actual native proof. MapLibre BSD-3-Clause license is bundled; provider/data/style licenses retain upstream attribution.
